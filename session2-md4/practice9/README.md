# Mini hệ thống xử lý đơn hàng

## Lựa chọn module
Dự án sử dụng chuẩn **ES Modules (ESM)** vì:
1. ESM là tiêu chuẩn mô-đun chính thức của ngôn ngữ JavaScript/ECMAScript, được hỗ trợ gốc trong các phiên bản Node.js hiện đại.
2. Cú pháp `import`/`export` trực quan và an toàn hơn tại thời điểm biên dịch so với CommonJS.
3. Phù hợp với định hướng phát triển hiện nay của hệ sinh thái Node.js và các thư viện hiện đại.
